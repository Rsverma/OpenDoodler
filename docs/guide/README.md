# OpenDoodler User Guide

A walkthrough of everything in the editor. If you haven't installed OpenDoodler yet, start with
[Installing OpenDoodler](../installing.md).

1. [Getting Started](getting-started.md) — the Launch screen, creating/opening a project, saving,
   and crash recovery.
2. [The Editor Canvas](editor-canvas.md) — adding, moving, resizing, and arranging graphics; the
   Layers panel; snapping; zoom/pan.
3. [Library & Graphics](library-and-graphics.md) — browsing/searching graphics, adding text, the
   Library Manager (import/delete/cleanup), and the scene-template gallery.
4. [Scenes & Timeline](scenes-and-timeline.md) — adding/reordering/deleting scenes, transitions,
   voiceover, background music, and the playhead.
5. [Project Settings](project-settings.md) — board type, entrance style, stroke, aspect ratio.
6. [Preview & Export](preview-and-export.md) — previewing your project and exporting to MP4.
7. [Keyboard Shortcuts](keyboard-shortcuts.md) — the full reference list.
