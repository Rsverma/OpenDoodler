# Keyboard Shortcuts

[← Back to guide index](README.md)

| Shortcut | Action |
|---|---|
| `Ctrl+N` | New project |
| `Ctrl+O` | Open project |
| `Ctrl+S` | Save project |
| `Ctrl+Z` | Undo |
| `Ctrl+Y` | Redo |
| `Ctrl+C` | Copy selected graphic |
| `Ctrl+X` | Cut selected graphic |
| `Ctrl+V` | Paste graphic |
| `Delete` | Delete selected graphic(s) |
| `←` `→` `↑` `↓` | Nudge selected graphic(s) by 1px |
| `Shift` + `←` `→` `↑` `↓` | Nudge selected graphic(s) by 10px |

## Canvas-only (mouse)

| Input | Action |
|---|---|
| `Ctrl` + mouse wheel | Zoom in/out, anchored to the cursor |
| Middle-mouse drag | Pan the canvas |

## Timeline-only (mouse)

| Input | Action |
|---|---|
| `Ctrl` + mouse wheel | Zoom the timeline in/out |
| Mouse wheel | Scroll the timeline horizontally |

These aren't remappable yet.
